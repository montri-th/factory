Set 2026-11-05 (release 0.1.0, extended in 0.2.0) on the owner request “จากที่เราทำ demo ของ CityMETER: Hotel มาแล้ว ใน https://montri-th.github.io/hotel ขอให้ทำแบบเดียวกันให้กับ CityMETER: Factory แล้ว publish ที่ https://github.com/montri-th/factory โดยใช้ข้อมูลจาก [the factory research master, tab gid 2026110418] และ ข้อมูลประกอบจาก [the research Drive folder] ซึ่งรวบรวมมาจาก งานเดิมใน production ที่เป็น CityMETER: Factory รายโรงงาน”. “แบบเดียวกัน” carries over the contracts of CityMETER · Hotel 0.3.6 (code base: montri-th/hotel @177e592) wherever they apply to factories; hotel-only parts (stations, chains, logos of chain brands, recorded prices, stay sites) are not part of this product.
Release 0.2.0 (owner 2026-11-05, “ทำไมจำนวนโรงงานในเวบถึงมีน้อยจัง ใน google sheet มีเกือบ 80,000 แห่ง” → “ขยายเลย”): the rows are every core registration of `02_FACTORIES` (74,047), not only the 7,175 FIDs of `18_WORKERS_P90`; the 95+ registrations stay as a size filter (`p90`) and a lens in every area panel.

- Apply current LDS 0.9.7 (v0.9.7-owner.1, standalone-0.9.7-r1, color-srgb-10) and preserve the map-first CityMETER layout. Colours come only from `assets/theme.css`, `js/scales.js` and `js/cues.js`; never approximate a value by eye. Analytical colours are the same HEX on both themes; EVID-05 map treatments use the `dataState` tokens. `npm run check:lds -- --lds <base> --li <profile>` compares every shipped value with the source files.
- Read `PRODUCT_STATEMENT.md` before changing what the first screen argues. The question is “คนงานโรงงานกระจุกอยู่ตรงไหน และทำงานในอุตสาหกรรมอะไร”.
- Scope is part of the name, never a caveat: “ทะเบียนโรงงานทุกขนาด · กรอ. นอกนิคมอุตสาหกรรม · อก.” in the panel heading, “CityMETER Factory · ทะเบียนโรงงาน” and “ทะเบียน กรอ. นอกนิคมอุตสาหกรรม · อก.” in every provenance line. Rows are the FIDs of `02_FACTORIES` (DIW class 2/3 lists = `outside_estate_source_scope_DIW_catalog`, MOI-only = `unknown_estate_context`). Worker figures are `คนงานรวม` of the DIW exports, checked against `18_WORKERS_P90` at build time (the build stops on a difference).
- Measure is a contract (`js/model.js#METRICS`, `rowValue`): Σ workers (“คน”) by default, registrations (“ทะเบียน”) on the switch; both are totals in the LDS `count` family. A registration without a worker figure (`row.workers = null`) adds nothing, reads “ไม่มีตัวเลขคนงาน” (or “—”), and an area whose registrations all lack one is EVID-05 no data (the hatch) — never 0. The map, legend, labels, Aha, ranks and charts read the same measure. Never call a figure employment, a labour market, capacity, output, sales, a market share or a density; a registration is never “a plant” or “a company” in copy that counts.
- Aha first, in 3D: the first paint frames up to three เขต/อำเภอ with the most of the measure in the province that holds the most of it at district level (`auto`). Show the share (Σ focus ÷ the province's whole total in the selection), numerator and denominator, the industry families of the focus as bars (each share's numerator and denominator in its title and accessible text) and the district with the most outside that province with its first family. Never cut through a tie, never focus every district that holds the measure (`js/area-insight.js`). Snapshot numbers in the handoff JSON are fixtures, never UI constants.
- Membership is the district matched at build time from the registration's own district label (`row.admin`: name · province). Never re-assign by point-in-polygon or by a name at runtime. A source point outside the registration's own district is withheld at build time (`row.off`, “ไม่แสดงพิกัด”), never used to move it.
- Industry: the official DIW group (`02_TYPES.official_industry_group_raw`) on every row; ten families for the categorical cue (`scripts/build-data.py#FAMILIES`, `js/cues.js#GROUP_SERIES`, DATAVIZ-05). A family is a presentation grouping; the DIW group name is shown wherever a group is named. Ordinal bars (worker bands, functional classes, DIW groups) use one neutral foundation fill.
- The 95+ lens (`row.p90`, `js/model.js#lensOf`) and the functional classes (`classMixOf`) are read from the same rows. The industrial-area register (`01_ESTATES`, names, type and official page only) is context and never added to the product's figures. Estate geometry: only the 46 OpenStreetMap outlines the estate master selected for the demo (CityMETER Industrial Estate, `DEMO_BOUNDARIES`, ODbL 1.0) are drawn, as quiet context (release 0.6.0); no other boundary until the master selects one and its rights are cleared. A list or an outline never says which registration lies in an estate.
- Nearby set (`js/profile-model.js#nearbyOf`): same family, workers ½–2× (any size when the registration has no figure or 0), straight line ≤ 3 km, every row of the dataset, nearest first; headed “โรงงานใกล้เคียง” with the rule as chips, every registration within 3 km beside it; never “คู่แข่ง” or a supply chain.
- Privacy and publication: a name written as a natural person's is withheld with its point (“ผู้ประกอบการบุคคลธรรมดา”) and never sent to Google; never copy addresses, raw MOI operator names, the 2025 operator label, operator context or legal/parent ids, researcher notes, review fields, evidence flags, source record ids, logo URLs or raw records (`meta.excludedFields`). Source links are public https pages only, never the production API. Never commit the internal research sheet or its export, private Drive/Sheet URLs, credentials, the full LDS library or the Location Intelligence Profile. Never put Landometer prices, contracts, proposals or pipeline in this repository.
- Copy (Hotel 0.3.1 rule, owner 2026-11-01 “กระชับอ่านเข้าใจง่าย ใช้ symbol, logo, icon, charts มาช่วยทำให้ text กระชับ … ไม่มี caveats เลย และเป็นธรรมชาติ”): short natural Thai in the ICP's words (คนงาน โรงงาน ทะเบียน อุตสาหกรรม อำเภอ นิคม โรงงานใกล้เคียง), pictograms (factory, workers, estate, status, class from `scripts/build-pictogram-font.py`) and small bar charts carry what a sentence used to; units on every number; a number and its unit never split across lines; limits live behind “วิธีนับ” (`DATA_METHOD.md`), never on screen (`tests/views.test.js`). No static counts in page copy.
- Every panel view ends with exactly one provenance line (`provenance()` in `js/panel.js`): dataset · source · date · boundary, then “วิธีนับ”; the estate register and terrain sources join the source part when the view shows them.
- Carried over unchanged from Hotel 0.3.6 (read `montri-th/hotel` AGENTS.md for the reasons): the national scale (outlines per province on demand, never all 77 up front), focus + quiet context, one symbol per row with a point (never clustered), symbol area by the quantity (`js/model.js#pinRadius`), names near the middle of the view (`js/labels.js`; text labels, ranked by `row.importance`), the building view and MapLibre guards pinned at 5.6.2 (`js/shell/camera.js`, `js/massing.js`, `js/shell/venue-xray.js`, `js/shell/maplibre-guard.js`, `GEOJSON_MAXZOOM`), a registration with a point always opening the two-point view of a building (the one its point falls in, else the nearest drawn within 300 m, then 800 m — a camera choice, never a join), buildings per area (`js/shell/building-units.js`, the 15 % rule of the hotel units), terrain at hilly sites (`js/shell/terrain.js`), the phone dock layout, basemap water, outbound Google actions as a plain search (`js/ask.js`), the breadcrumb with production codes and `/D/` deep links (`?d=factory`).
- Charts: matrix cells are equal in size; district bars carry the map's ramp colour. No CSV download. No decorative brackets or coloured left rails. Visible focus everywhere. Review Thai at desktop and 390 px in light and dark before claiming done; local renders are not proof of a live release — run `npm run verify:live` and walk the live site.
- Releases bump one cache tag `?v=YYYYMMDD-rN` on every entry in `index.html` and, through the import map there, on every ES module, together with `package.json` version, `design-intent.json` and the handoff JSON `productVersion` (`tests/release.test.js`). A new module must be added to the import map. Icon fonts inside the stylesheets carry `?v=<first 8 hex of their SHA-256>` (`tests/icons.test.js`).
- Data changes are made in the research sheet itself, then re-exported and rebuilt with `scripts/build-data.py` — never patched in `data/`.

## Discovery and dataset group (owner decision 2026-11-08)

- Every page carries `<meta name="robots" content="noindex, nofollow">`. The owner does not want search engines to index the demos while developers keep building on them: “ไม่ต้องการให้เสิช engine เข้ามาดูเดโม แต่อยากให้ dev นำ demo บน github ไป vibe coding ต่อได้ง่าย คือ SEO อันไหนจัดการได้จัดการไปเลย แต่ยังไม่ต้องให้ crawler เข้ามา index”. Keep the rest of the SEO metadata ready for production, do not block crawlers in a robots.txt (they must be able to read the noindex), add no sitemap, and never point `rel="canonical"` at landometer.com from a noindex page. `tests/discovery-and-group.test.js` guards this.
- The panel eyebrow `CITYMETER · LOCATION` follows the dataset registry (`R01_DATASETS.dataset_group`; owner: “ใช้ตามทะเบียนทั้งหมด”). This dataset is LOCATION in the registry read on 2026-11-08; change the label only when the registry changes.
