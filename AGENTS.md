## Discovery and dataset group (owner decision 2026-11-08)

- Every page carries `<meta name="robots" content="noindex, nofollow">`. The owner does not want search engines to index the demos while developers keep building on them: “ไม่ต้องการให้เสิช engine เข้ามาดูเดโม แต่อยากให้ dev นำ demo บน github ไป vibe coding ต่อได้ง่าย คือ SEO อันไหนจัดการได้จัดการไปเลย แต่ยังไม่ต้องให้ crawler เข้ามา index”. Keep the rest of the SEO metadata ready for production, do not block crawlers in a robots.txt (they must be able to read the noindex), add no sitemap, and never point `rel="canonical"` at landometer.com from a noindex page. `tests/discovery-and-group.test.js` guards this.
- The panel eyebrow `CITYMETER · LOCATION` follows the dataset registry (`R01_DATASETS.dataset_group`; owner: “ใช้ตามทะเบียนทั้งหมด”). This dataset is LOCATION in the registry read on 2026-11-08; change the label only when the registry changes.

## Shared shell — address, history, breadcrumb, tab title (owner 2026-11-08, release 0.3.0)

- Phase 1 of the demo platform (owner 2026-11-08 20:04: “ทำงาน ตาม demo platform review ระยะถัดไปต่อเลยครับ”): `js/shell/` is citymeter-shell 0.1.0, the same bytes in Hotel, Office, Hospital, School, Government Office and Factory. Never edit it in one repository: change it in every repository that carries it and rebuild `js/shell/manifest.json` from the bytes (`tests/shell.test.js`, the same file everywhere, checks each hash).
- The address uses the production grammar: `?d=factory&at=BKK/D/1039&e=<kind>:<key>` with `m`, `f.<filter>`, `focus`, `view` and `v3d`. `at` is the production path after /v3/citymeter/, letter for letter; a subdistrict link opens its district, a local unit or a locale link its province. Opening an area or an item adds a browser history entry, so the back button goes up a level; filters, measure, view and 3D replace the entry. Old links (`?area=`, `?province=`, `?factory=`, `?view3d=`) still open and are rewritten. The page keeps its own parameter names inside (`saveURL` / `restoreFromURL`); the codec in `js/app.js` maps them. The `e` kinds (`factory`) are provisional until the dataset registry declares them.
- The tab title is `[page] · CityMETER` within 60 characters (LDS FAVICON-01): the measure and the place (“คนงาน เขตวัฒนา”), an item's name. The page has one H1, the dataset name; the loading card's heading is an h2.
- Kept as it was: the 3D first paint, the breadcrumb levels and the camera. The review's plan view for area pages waits for the owner, because it would change “Aha first, in 3D” above.
