# CityMETER: Factory

**คนงานโรงงานกระจุกอยู่ตรงไหน และทำงานในอุตสาหกรรมอะไร** — เดโมแผนที่ 3 มิติของทะเบียนโรงงานทุกขนาดของกรมโรงงานอุตสาหกรรม (กรอ.) และกระทรวงอุตสาหกรรม (อก.) ทั่วประเทศ 74,047 ทะเบียน อ่านจำนวนคนงานตามทะเบียนเป็นยอดต่อเขต/อำเภอ พร้อมอุตสาหกรรม ขนาด (รวม “คนงาน 95 คนขึ้นไป”) หน้าที่ สถานะตาม อก. รายชื่อนิคมและสวนอุตสาหกรรม โรงงานใกล้เคียงขนาดใกล้กัน และที่มาของทุกตัวเลข

- เว็บ: https://montri-th.github.io/factory/
- ระบบจริงของ CityMETER: https://landometer.com/v3/citymeter?d=factory
- รุ่น 0.2.0 · 5 พฤศจิกายน 2569 · ชีตวิจัยตรวจแหล่ง 4 พฤศจิกายน 2569 · ขอบเขต production อ่าน 1 พฤศจิกายน 2569 (ชุดเดียวกับ CityMETER: Hotel) · รุ่น 0.1.0 นับเฉพาะ 7,175 ทะเบียนที่มีคนงาน 95 คนขึ้นไป ซึ่งตอนนี้เป็นตัวเลือกในตัวกรองขนาด

ข้อค้นพบแรก (snapshot ปัจจุบัน ไม่กรอง): **72% ของคนงานโรงงานในสมุทรปราการ (330,987 จาก 457,353 คน) อยู่ใน 3 อำเภอ — บางพลี เมืองสมุทรปราการ พระประแดง** · อุตสาหกรรมหลักของ 3 อำเภอนี้: ยานพาหนะและเครื่องจักร 18% · สิ่งทอ เครื่องแต่งกาย หนัง 17% · โลหะ 16% · อันดับ 1 นอกสมุทรปราการคือเมืองสมุทรสาคร 264,666 คน (อาหารและเครื่องดื่ม 42%) มากกว่าทุกอำเภอของสมุทรปราการ · โรงงานคนงาน 95 คนขึ้นไป 7,175 ทะเบียนมีคนงาน 65% ของทั้งหมด

> ชุดข้อมูล CityMETER Factory · ทะเบียนโรงงาน จาก ทะเบียน กรอ. นอกนิคมอุตสาหกรรม · อก. · ตรวจ 4 พ.ย. 2569 · ขอบเขต เขต/อำเภอของ CityMETER ทั่วประเทศ · วิธีนับ: `DATA_METHOD.md`

## ใช้งาน

```sh
npm start   # http://127.0.0.1:4173/
npm test    # unit tests บนข้อมูลจริง (node --test)
```

เป็น static site ไม่มี build step และไม่ต้อง `npm install` (Node ≥ 20 สำหรับ tests, Python 3 สำหรับ server) แผนที่โหลด MapLibre GL 5.6.2 จาก unpkg และ tiles/glyphs จาก OpenFreeMap; basemap สร้างเองใน `js/shell/map-style.js` กราฟไม่ใช้ไลบรารีภายนอก ถ้าแผนที่โหลดไม่ได้ ข้อค้นพบ แผง กราฟ และตารางยังใช้ได้

## สิ่งที่สำรวจได้

- **ข้อค้นพบแรกแบบ 3 มิติ:** โฟกัสเขต/อำเภอที่มีคนงานมากที่สุด (ไม่เกิน 3) ของจังหวัดที่มีคนงานมากที่สุด บอกสัดส่วน ตัวตั้ง ตัวหาร อุตสาหกรรมหลักของพื้นที่นั้นเป็นแท่งพร้อมตัวตั้งตัวหาร และพื้นที่ที่มากที่สุดนอกจังหวัด — ไม่ตัดผ่านค่าที่เท่ากัน และไม่โฟกัสทุกอำเภอของจังหวัด
- **คนงาน | โรงงาน:** สลับมาตรวัดในคำอธิบายแผนที่ แผนที่ ป้าย ข้อค้นพบ อันดับ และกราฟเปลี่ยนพร้อมกัน (สเกล `count` ครบ 41 ระดับของ LDS ทั้งสองมาตรวัด เพราะเป็นยอดรวมที่ไม่มีตัวหาร)
- **อุตสาหกรรม:** 21 กลุ่มอุตสาหกรรมของ กรอ. (อีก 3,114 ทะเบียนไม่ระบุกลุ่ม) จัดเป็น 10 หมวดสำหรับสีและรูปทรงของสัญลักษณ์ กรองตามหมวด ดูทุกกลุ่มของ กรอ. ในกราฟ และเห็นกลุ่มของทุกโรงงานในแผง
- **ขนาด:** ตัวกรองขนาดมี “คนงาน 95 คนขึ้นไป” ช่วง 0–9 ถึง 5,000+ คน และ “ไม่มีตัวเลขคนงาน” (2,923 ทะเบียนที่แหล่งไม่มีตัวเลข — แสดงเป็นคำนี้หรือลายเส้นทแยง ไม่ใช่ 0)
- **ขนาดสัญลักษณ์ตามคนงาน:** พื้นที่ของสัญลักษณ์เพิ่มตามคนงาน (200 · 1,000 · 5,000 คนในคำอธิบาย; โรงงานเล็กและทะเบียนที่ไม่มีตัวเลขเป็นจุดเล็กสุด) สีและรูปทรงยังบอกหมวดอุตสาหกรรม หนึ่งสัญลักษณ์ = หนึ่งทะเบียนที่มีจุดในแหล่ง (15,654 ทะเบียน)
- **ชื่อโรงงานกลางจอ:** ตั้งแต่ระดับไซต์ ชื่อสั้น (ไม่มี “บริษัท … จำกัด”) ของโรงงานที่คนงานมากก่อน ไม่เกิน 9 ป้าย (มือถือ 5) ชี้แล้วเห็นการ์ด: หมวด คนงาน กลุ่ม กรอ. สถานะ อก. ภูมิประเทศ
- **โรงงานหนึ่งแห่ง:** กดโรงงานที่มีพิกัด แผนที่เปลี่ยนเป็น 3 มิติและเปิดมุมมองอาคาร 2-point perspective (อาคารที่จุดอยู่ในขอบ หรืออาคารที่ใกล้จุดที่สุด) · คนงานและอันดับทั่วประเทศ หมวดและกลุ่ม กรอ. หน้าที่ (ผลิต บริการ อื่น ๆ) จำพวก สถานะตาม อก. พร้อมวันที่ ประเภทโรงงานและรหัส ภูมิประเทศ · **โรงงานใกล้เคียง** (หมวดเดียวกัน · คนงาน ½–2 เท่า · ≤ 3 กม.)
- **บริบทพื้นที่:** ทะเบียน 95+ คนของพื้นที่และส่วนของคนงาน · หน้าที่ของโรงงาน (ผลิต บริการ อื่น ๆ รอตรวจ) · รายชื่อนิคม สวน และเขตอุตสาหกรรมของจังหวัดพร้อมลิงก์หน้าทางการ (เป็นรายชื่อ ไม่วาดขอบเขต)
- **อาคารรายพื้นที่:** อปท. (กรุงเทพฯ รายเขต) ที่ CityMETER: Hotel ตัดสินไว้ใช้อาคาร CityMETER Building V4 เมื่อมีอาคารมากกว่า OpenStreetMap ตั้งแต่ 15% ขึ้นไป พื้นที่อื่นใช้ OpenStreetMap ความสูงของ CityMETER เป็นค่าประมาณ
- **ภาษา:** สั้น ใช้ไอคอนและกราฟแท่งเล็กแทนประโยค ไม่มีคำเตือนบนหน้าจอ ทุกหน้าจบด้วยบรรทัดที่มาและลิงก์ “วิธีนับ” (กติกาเดียวกับ CityMETER: Hotel 0.3.1)
- **มือถือ:** ข้อค้นพบกับคำอธิบายแผนที่รวมเป็นแถบเดียวด้านล่าง ใช้สองนิ้วซูม แผงข้อมูลสูง 56% ของจอและเปิดตรงโรงงานหรือพื้นที่ที่เลือก
- **ถามต่อใน Google:** ทุกมุมมองมีปุ่มถาม Google AI ด้วยคำถามที่ตรงกับสิ่งที่กำลังดู (Google Search ที่ AI Overview ตอบด้านบน) พร้อม Google Maps และ Street View เมื่อมีพิกัด · คำตอบของ Google ไม่ถูกนำมาเป็นข้อมูลในหน้านี้ · ทะเบียนที่ชื่อเป็นบุคคลธรรมดาไม่ถูกค้นด้วยชื่อ
- **เส้นทาง:** ประเทศไทย › จังหวัด › เขต/อำเภอ ใช้รหัสเดียวกับ CityMETER production และเปิดพื้นที่เดียวกันในระบบจริงได้ (`?d=factory`)
- **ลิงก์ตรง:** `?metric=count` · `?area=1103` · `?areas=1101,1103,1104` · `?areas=all` · `?province=SPK` · `?group=food` · `?size=p90` (คนงาน 95 คนขึ้นไป) · `?size=w4` · `?size=none` · `?cls=manufacturing` · `?factory=<เลขทะเบียน>` · `?view=mix` · `?view=industries` · `?view3d=0`

## ข้อมูล

- `data/factories.json` — 74,047 ทะเบียนโรงงาน (FID) จากแท็บ `02_FACTORIES` ของชีตวิจัย ตัวเลขคนงานจากข้อมูลเปิดของ กรอ. จำพวก 2–3 (ตรวจตรงกับแท็บ `18_WORKERS_P90` ทุกทะเบียน) และรายชื่อนิคม/สวนอุตสาหกรรม 106 แห่ง (ไม่เผยแพร่ชีตหรือไฟล์ export) — `scripts/build-data.py` · ขนาด 11.9 MB (ราว 1.9 MB เมื่อส่งแบบ gzip)
- `data/area-index.json`, `data/frames/{CODE}.json`, `data/provinces.geojson`, `data/boundary-receipts.json` — เขต/อำเภอและจังหวัดของ CityMETER production ชุดเดียวกับ CityMETER: Hotel (`montri-th/hotel@177e592`)
- `data/building-units/` — แหล่งอาคารราย อปท./เขต จาก CityMETER: Hotel (เกณฑ์ 15%) ใช้ตามเดิม
- วิธีทั้งหมด ข้อจำกัด และงานวิจัยที่ต้องตามต่อ: `DATA_METHOD.md` · กลยุทธ์ผลิตภัณฑ์: `PRODUCT_STATEMENT.md` · สำหรับนักพัฒนา: `handoff/START_HERE.md` · สำหรับ agent: `llms.txt`
