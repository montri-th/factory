# CityMETER · Industrial Estate

**นิคมอุตสาหกรรมอยู่ตรงไหน ใครพัฒนา และในทำเนียบมีใครบ้าง** — เดโมแผนที่ของนิคม สวน และเขตอุตสาหกรรม 106 รายการจากทะเบียนวิจัยนิคมอุตสาหกรรม (registry `research.TH.industrial_estates`, สัญญาข้อมูล `industrial-estate-demo/1.0.0`) พร้อมขอบเขตจาก OpenStreetMap 46 แห่งที่ทะเบียนเลือกให้แสดง รายชื่อในทำเนียบโรงงานในนิคมของ กนอ. 6,811 รายชื่อใน 56 นิคม โลโก้นิคมหรือบริษัทผู้พัฒนา และโรงงานรอบนิคมจาก CityMETER Factory

- เดโม (GitHub Pages): https://montri-th.github.io/factory/industrialestate/ · English: `?lang=en`
- เดโม (CityMETER Pages): https://citymeter.pages.dev/industrialestate/
- เดโมคู่กัน: CityMETER Factory — https://montri-th.github.io/factory/ (นิคมเดียวกันเปิดได้ทั้งสองทาง)
- สถานะ: ต้นแบบสาธารณะสำหรับทดลองและพัฒนาต่อ (noindex) ไม่ใช่ CityMETER ฉบับใช้งานจริง

> ชุดข้อมูล CityMETER Industrial Estate · จาก ทะเบียนวิจัยนิคม สวน และเขตอุตสาหกรรม · ทำเนียบ กนอ. 4 พ.ย. 2569 · ขอบเขต OpenStreetMap 25 ต.ค. 2569 · ตรวจ 26 ต.ค. 2569 · ขอบเขต จังหวัดตามแหล่ง · วิธีนับ: `DATA_METHOD.md`

## หน้าจอ

- **ข้อค้นพบแรก:** 62 จาก 106 รายการอยู่ใน 3 จังหวัด EEC (ชลบุรี 31 · ระยอง 23 · ฉะเชิงเทรา 8) — สัดส่วนของรายการตามจังหวัดที่แหล่งระบุ ไม่ใช่การจัดอันดับนิคม
- **แผนที่:** ขอบเขตนิคม 46 แห่ง ระบายสีตามจำนวนรายชื่อในทำเนียบ กนอ. บนสเกล LDS `count` 41 ค่า นิคมที่ไม่มีรายชื่อในทำเนียบรอบนี้เป็นลายขีด (EVID-05 no data ไม่ใช่ 0) ชื่อนิคมเป็นป้ายบนแผนที่ อาคาร 3 มิติในนิคมที่เปิด และจุดโรงงานรอบนิคม (สัญลักษณ์ตามกลุ่มอุตสาหกรรม ขนาดตามคนงาน)
- **นิคมหนึ่งแห่ง:** โลโก้ (นิคม บริษัทแม่ หรือผู้พัฒนา ระบุว่าเป็นโลโก้แบบไหน) ประเภท จังหวัด รายชื่อในทำเนียบ ชื่อที่ตรงกับทะเบียนโรงงาน โรงงานรอบนิคม ≤ 3 กม. ตามกลุ่มอุตสาหกรรม รายชื่อในทำเนียบ (ค้นได้ ชื่อบุคคลธรรมดาไม่แสดง) และลิงก์ไปทะเบียนเดียวกันใน CityMETER Factory
- **จังหวัด · ประเภท · ผู้พัฒนา:** รายการต่อจังหวัด ประเภท และผู้พัฒนา/เครือ (ชื่อย่อตามที่องค์กรใช้ เช่น กนอ.)
- **ตัวกรอง:** ค้นหา ประเภท จังหวัด มีขอบเขต มีรายชื่อในทำเนียบ · ตาราง · กราฟจังหวัดและผู้พัฒนา
- **ภาษา:** ไทย/อังกฤษ (`?lang=en`) ชื่อที่แหล่งไม่มีภาษาอังกฤษคงเป็นภาษาไทย

## ที่อยู่หน้าเว็บ

ไวยากรณ์เดียวกับเดโม CityMETER อื่น (citymeter-shell): `?d=industrialEstate&at=<จังหวัด>&e=estate:<estate_id>` พร้อม `f.<ตัวกรอง>` และ `v3d` — เช่น `?d=industrialEstate&at=CBI&e=estate:EST-IEAT-2722`

ใน CityMETER Factory นิคมเดียวกันเปิดด้วย `?d=factory&e=estate:<estate_id>` (ขอบเขตบนแผนที่และทะเบียนโรงงานรอบนิคม ≤ 3 กม.)

## ไฟล์

- `index.html` · `styles.css` · `navigation.css` · `assets/` — หน้าเว็บ (LDS 0.9.7; ฟอนต์ ไอคอน สี จากชุดเดียวกับ Factory)
- `js/` — `app.js` (แผนที่และการเลือก) · `model.js` (ข้อมูลและการนับ ไม่มี DOM) · `panel.js` (แผงอ่าน) · `labels.js` (ป้ายชื่อบนแผนที่) · `lang*.js` (ภาษา) · `js/shell/` (citymeter-shell 0.5.4 ไบต์เดียวกับทุกเดโม)
- `data/estates.json` — 106 รายการ (ชื่อ ประเภท จังหวัดตามแหล่ง หน้าทางการ ขอบเขตที่เลือก ทำเนียบ ชื่อที่ตรงกับทะเบียนโรงงาน โลโก้ โรงงานรอบนิคม)
- `data/boundaries.geojson` — ขอบเขต OpenStreetMap 46 แห่ง (© OpenStreetMap contributors, ODbL 1.0; ลดจุดที่ 1.5 ม.)
- `data/directory.json` — ทำเนียบ กนอ. ตามนิคม (โหลดเมื่อเปิดนิคม)
- `data/around.json` — จุดโรงงานรอบนิคมจาก CityMETER Factory (โหลดเมื่อใช้)
- `assets/logos/` — โลโก้ที่ SHA-256 ตรงกับ `LOGO_LIBRARY` ของทะเบียนวิจัย โดยแถวของ `LOGO_LIBRARY_R8` ใช้แทนแถวเดิม (`manifest.json` → `excluded`: ภาพ Bluetech ที่เลิกใช้)
- `scripts/build-data.py` · `scripts/build-logos.py` — สร้างข้อมูลและโลโก้จากชีตวิจัย (ไม่เผยแพร่ชีตหรือไฟล์ export)
- `../data/estate-context.json` — บริบทนิคมที่ CityMETER Factory ใช้ (สร้างพร้อมกันด้วย `build-data.py`)
